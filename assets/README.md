# Brane OS brand assets

The Brane OS symbol is an abstract multidimensional membrane: three continuous surfaces interconnect to represent modular services, secure device branes, and the AI layer operating as one auditable system.

## Assets

| Asset | Purpose |
| --- | --- |
| [`brane-os-mark.png`](brane-os-mark.png) | Primary full-color mark with a transparent background. Use it in the README, presentations, release artwork, and high-fidelity interfaces. |
| [`brane-os-logo.svg`](brane-os-logo.svg) | Lightweight vector adaptation for small UI surfaces, documentation, and contexts where SVG is preferred. |

## Core palette

| Color | Hex | Role |
| --- | --- | --- |
| Electric cyan | `#72F6FF` | Connectivity and active system state |
| Brane blue | `#168BFF` | Primary identity color |
| Deep blue | `#1236B8` | Structural depth |
| Dimensional violet | `#7B4FE8` | AI and multidimensional layers |
| Signal magenta | `#FF4FD8` | Restricted accent for intersections and alerts |
| Kernel black | `#030712` | Preferred dark background |

## Usage

- Keep clear space around the mark equal to at least 12% of its width.
- Prefer dark, neutral backgrounds when using the full-color mark.
- Do not stretch, rotate, recolor, add text inside, or place the mark in a decorative frame.
- At very small sizes, use the SVG adaptation and avoid reproducing the internal particle detail.
- Write the project name as **Brane OS** in prose and use **BraneOS** only when a compact product label is required.
